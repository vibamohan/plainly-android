# Plainly

Plainly is an Android app that helps people understand letters and other documents. It reads text from photos and PDFs on the device using text extraction and OCR. The app highlights possible actions, dates, and phrases that may deserve a closer look, with links to the supporting text. Its indicators are not fraud probabilities and cannot verify a sender or prove that a document is safe. Plainly is designed to make document review clearer while keeping document analysis on the device.
